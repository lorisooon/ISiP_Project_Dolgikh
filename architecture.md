# Архитектура программного средства: ShoesFactoryProg

**Архитектурный стиль:** Трёхуровневая модель (клиент-серверная архитектура).  
1. **Уровень представления:** Интерфейс пользователя, панель управления производством, складской и торговый интерфейсы.  
2. **Уровень бизнес-логики:** Модуль авторизации, модуль материалов, производственный модуль, модуль качества, складской и торговый модули, модули отчётности, HR и финансов.  
3. **Уровень данных:** Централизованная база данных обувной фабрики.  
**Сценарий взаимодействия:** Пользователь формирует заказ → Производственный модуль проверяет и резервирует сырьё через Складской модуль → Запускается производство → Обновляются остатки в БД.
